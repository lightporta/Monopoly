# 仙境海岸·大富翁 v4 游戏规则

[English](game-rules.en.md) · [共享引擎接口](../../shared/CONTRACT.md)

v4 的单机与联机共用 `shared/index.js`。真人、AI 和服务器执行相同的合法动作、租金、债务和胜负规则。棋盘保留 36 格和 21 处烟台地标；以下规则替代 v3 文档。

## 对局与回合

支持 2–4 名玩家，每名玩家初始现金 **12,000**。默认上限 **40 个完整轮次**；一个轮次包含每个席位的一次回合机会，破产席位自动跳过。共享引擎接受 1–200 轮，联机房间接受 10–100 轮。

每个正常回合依次执行：

1. 掷骰：先结算一次投资分红，再掷两枚公平六面骰，按点数前进。
2. 落格：自动处理传送、卡牌、休息、租金等效果。落到无主地产必须购买或放弃，不能直接结束回合。
3. 管理：购买之后或无需购买时，可建造、养殖、装备、卖出升级、抵押、赎回及投资；现金和资产条件满足时可以连续管理。
4. 结束回合：切换到下一存活席位。

**双数不追加回合**，没有三连双数处罚和重掷券。桥上的休息会消耗玩家下一次完整回合机会；跳过时不掷骰、不分红，然后自动交给下一玩家。

## 棋盘、移动和美食

普通前进越过或正好抵达 0 格时奖励 **1,200**，并获得一份美食。每累计四份美食自动兑换 **1,000**，计数归零。当前版本采用可见的累计数量，不再维护四种独立美食卡牌。

| 格号 | 地点 | 固定效果 |
| --- | --- | --- |
| 5 | 烟台山灯塔 | 自动传送到 24 号蓬莱阁，处理目的地 |
| 13 | 海昌鲸鲨馆 | 获得 300，随后进入管理阶段 |
| 18 | 养马岛跨海大桥 | 下一次自己的回合跳过 |
| 25 | 八仙渡海口 | 自动传送到 27 号长岛，处理目的地 |
| 35 | 烟台蓬莱国际机场 | 自动传送到 0 号起点 |

**传送不发起点奖励、不加美食**，包括机场传回起点。传送目的地上的购买与租金继续正常处理。v4 不提供自选传送目的地。

## 地产、建造与租金

地产价格、基础租金和单级建筑成本来自 `shared/data.js`；界面和服务端使用这一份数据。允许单独建设地产，不要求先集齐整组。每处最多 **3 级建筑**，每级支付该地的 `buildCost`。

```text
租金 = 向下取整(基础租金 × 建筑倍率 × 色组倍率 × 装备倍率)
建筑倍率：空地 1；1 级 3；2 级 6；3 级 10
色组倍率：达标 1.5，否则 1
装备倍率：已装备 1.2，否则 1
```

没有统一扣款翻倍。自己落在自己的地上不交租；已抵押地产不收租、不享受色组计数。

| 色组 | 地产数量 | 加成条件 |
| --- | --- | --- |
| 历史街区 | 4 | 4 块未抵押地产 |
| 海岸线 | 8 | 至少 4 块未抵押地产 |
| 仙山 | 5 | 5 块未抵押地产 |
| 温泉 | 4 | 4 块未抵押地产 |

色组加成适用于该组全部未抵押地产，包括已有建筑的地产。落入对手地产时租金由引擎立即结算，真人和 AI 均不能选择跳过。

## 养殖、装备与投资

**养殖**适用于月亮湾、养马岛、长岛、万鸟岛。每级成本 **1,000**，最多三级；自然经过起点时分别收益 **200 / 450 / 750**。养殖与房屋互斥；养殖不提高基础租金。卖光养殖或房屋后可以改走另一条发展路线。

**装备**对任何自有未抵押地产开放，每块成本 **1,000**、限一件，租金提高 **20%**。装备可与房屋或养殖共存；不再设置无法购买的机场供应点和四种独立装备。

**投资**在管理阶段购买，每人每种最多一份，另受全局份额限制：

| 项目 | 成本 | 每个正常自身回合分红 | 全局限额 |
| --- | --- | --- | --- |
| 海上风电场 | 2,500 | 55 | 2 份 |
| 海阳核电项目 | 4,000 | 90 | 1 份 |

分红仅在一次合法 `roll` 开始时结算。管理、刷新、重连和重复发送动作不会重复分红。刚购入的项目从下一次正常自身回合开始支付。没有手动卖出投资入口；欠债时按半价自动变现，释放全局份额。玩家破产或投降也释放份额。v4 以低生态减产表达核电风险，不再维护核事故的多回合停机和连锁项目。

## 海洋生态与卡牌

全局生态初始 **70**，范围 0–100。每抽机会卡增加 5，命运卡减少 5；完成一个轮次并进入下一轮时自然恢复 2，取值始终限制在范围内。

- 生态低于 50：养殖收益乘 0.75；低于 30：改乘 0.5。
- 生态低于 30：核电分红乘 0.5。
- 以上收益向下取整；风电、起点奖励和普通租金不受生态影响。

机会/命运各有四种等概率效果，先改变生态，再结算效果：

| 效果 | 机会 | 命运 |
| --- | --- | --- |
| 奖励 | +500 | +500 |
| 支出 | -200 | -600 |
| 小额奖励 | +300 | +150 |
| 生态结算 | 当前生态至少 50 时 +250，否则 -400 | 相同 |

单机和共享引擎模拟使用对局种子：固定种子和相同动作序列可以复现。在线服务端在每次掷骰前注入新的密码学随机熵，并剥离快照中的种子和内部随机状态；因此线上对局不能仅凭开局种子重放。

## 抵押、变卖与债务

建筑、养殖和装备按成本的 **50%** 回收。一次卖出操作依次尝试：减少一级房屋，否则减少一级养殖，否则出售装备。地产没有这些升级时才允许抵押，获得地价 **50%**；赎回成本为抵押本金 × **1.1**，向上取整。

租金、罚款和其他支出均走同一个债务处理流程：

1. 现金不足时，依固定地产顺序出售房屋、养殖和装备，筹够后停止。
2. 仍不足时，按持有顺序逆序以原成本 50% 变现投资份额。
3. 仍不足时，将未抵押地产以地价 50% 抵押，筹够后停止。
4. 向债权人支付实际筹得且不超过应付金额的钱。银行支出直接扣除。
5. 若仍无法足额支付，玩家破产，现金归零、退出后续回合，名下资产归银行并清空升级。

**房东最多收到实际收回金额**，未偿还部分不会凭空记入房东现金。所有路径共用此规则，没有“没钱就不付”的 AI 特例。

## 净资产与胜负

```text
净资产 = 现金
       + 自有地产原价 − 抵押本金
       + 房屋、养殖、装备投入的 50%
       + 投资成本的 50%
       + 符合条件的铁三角积分奖励
```

抵押本金在取得贷款时已经进入现金，因此在地产权益中扣除；借款不能抬高净资产。投资虽不能手动出售，但欠债时可按与估值相同的半价变现。

同时拥有烟台山、养马岛、蓬莱阁，三处均为 **3 级且未抵押**时，净资产额外计入 **3,000 积分**。它不是现金，不会重复发放；失去条件即不再计入。铁三角不提前结束游戏，取消“先到 30,000 立即胜利”。

- 仅剩一位未破产玩家时，该玩家立即获胜。
- 完成轮数上限后，所有未破产玩家统一比较净资产，最高者获胜。
- 完全相同的最高净资产允许多人共享冠军，顺序和座位不用于打破平局。
- 结束后引擎拒绝全部动作，不能再次掷骰或改资产。

## AI 与验证范围

AI 从 `getLegalActions` 返回的合法动作中决策，不能看未来骰子、改钱或逃租。简单、普通、困难使用不同的现金储备和收益判断；困难额外估计两骰移动、自动传送和桥上休息造成的落点概率，再评估租金与剩余轮数。决策可复现，难度不承诺每局必胜。

可运行：

```bash
npm test
npm run simulate -- --seeds 100
```

v4 参数校准使用 `balance-v4` 种子前缀、100 个种子、每种难度轮转所有座位，共 **1,200 局 AI 自博弈、290,603 个合法动作，全部终局**。普通对困难双人场景中困难胜利积分占比 52.5%；三种难度混合场景为简单 14.33%、普通 38.67%、困难 47%；同为普通的三席胜利积分占比为 31% / 36% / 33%。平局按人数平分胜利积分。

这些统计只验证该策略组在这些种子下的表现，不能代表真人胜率、全面公平性或公网部署效果。骰子运气仍会影响个别对局。

## v3 迁移差异

v4 使用新的状态与协议，不兼容 v3 存档、客户端和已运行房间。保留主题与核心资产玩法，同时主动精简：取消拍卖、玩家间交易、自选传送、重掷券、旅馆、独立美食牌堆、四类装备分支和核事故停机；固定传送、食品累计兑换、通用装备和低生态减产取代这些分支。前后端不再各维护一套规则。
