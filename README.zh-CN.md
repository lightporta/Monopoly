# 仙境海岸 · 大富翁

[English](README.md) · [简体中文](README.zh-CN.md)

烟台文旅主题网页大富翁，支持 2–4 位玩家：单人对战 AI、同设备真人轮流操作、跨设备房间联机。界面、地标、日志、规则及部署文档均提供中英文。

V4 将单机和联机的两套旧引擎合为一套，重新设计经济、AI 和胜负结算。服务端使用同一规则裁定联机操作，前端只负责展示和发送动作；删除了旧的重复规则和手动复制的生产 HTML。

## 启动

需要 **Node.js 22.12 及以上**。在仓库根目录执行：

```sh
npm ci
npm run dev
```

访问 [localhost:5173](http://localhost:5173)。此命令同时启动前后端，Vite 将 `/ws` 转发给 3000 端口。

生产模式或局域网跨设备游玩：

```sh
npm run build
npm start
```

访问 [localhost:3000](http://localhost:3000)，其他设备使用 `http://你的局域网IP:3000`。创建房间，分享六位房间码，其他真人加入并准备后由房主开始；也可以添加 AI 补位。互联网联机需要可访问的服务器，建议使用 HTTPS，本项目不提供服务器。

容器启动：`docker compose up --build -d`。必须保持单进程、单副本。HTTPS、Nginx 和环境变量见[部署指南](docs/deploy/deployment-guide.md)。本次本地验证没有运行 Docker、真实 TLS 或云服务器部署。

## 重构内容

- **共享规则**：强制支付租金，严格校验回合和阶段；现金不足统一出售升级、变卖投资、抵押、破产；只转移实际偿付金额。
- **双语界面**：重做首页、棋盘、资产管理、回合交接和结算；支持手机尺寸布局、查看任意地块、浏览器单机自动存档。无外部字体或媒体依赖。
- **联机后端**：稳定身份、私密重连令牌、房主转移、准备状态、机器人、请求去重与版本校验。刷新可恢复席位，超时由 AI 完成本回合；主动离开后席位永久转 AI。
- **AI**：三种难度均从合法动作中决策，考虑现金储备和收益；困难难度估计骰子、传送和休息带来的落点概率。没有金钱、骰子或免租特权。
- **工程交付**：统一根 lockfile、回归测试、浏览器测试、批量模拟、CI 配置及部署文件。

V4 的协议和存档格式与 V3 不兼容。本次规则主动精简了玩家交易、拍卖、自选传送、重掷券、旅馆及提前资产胜利；保留 36 格烟台地图、21 处地产、房屋/养殖、装备、能源投资、美食、生态和铁三角目标。

## 新规则概要

初始现金 **¥12,000**，每回合只掷一次骰子，随后处理购买选择和资产管理。租金与费用自动结算，自然经过起点获得 **¥1,200**、美食和养殖收入；传送不发起点奖励。每四枚美食兑换 **¥1,000**。

房屋与养殖互斥，均最多三级。集组租金增加 50%，装备增加 20%。风电/核电每有效回合分红 **¥55/¥90**，全局限购；生态会影响养殖与核电。资金不足按统一流程清算，不能跳过租金，也不会向房东凭空支付欠款。

最后存活者获胜；否则完成设置的完整轮次（默认 **40 轮**）后统一比较净资产，相同分数并列获胜。铁三角各三级增加 **3,000 结算分**，不发现金、不提前结束。详见[完整规则](docs/design/game-rules.md)，游戏内也可随时查看。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 同时启动开发前后端 |
| `npm run build` | 前端构建至 `monopoly/dist/` |
| `npm start` | 同端口提供生产网页与 `/ws` |
| `npm run check` | 规则/客户端/服务端回归 + 生产构建 |
| `npm run simulate -- --seeds 100` | 固定种子、轮转座位的 AI 自博弈 |
| `npx playwright install chromium` | 安装测试浏览器 |
| `npm run test:e2e` | 生产构建及 Chromium 用户流程测试 |

纯静态托管可玩单机，需上传 **完整 `monopoly/dist/` 目录**，包括 `assets/`；不支持双击 HTML 以 `file://` 打开。联机房间存在进程内存里，服务器重启后丢失；单机存档保存在浏览器。暂未实现账号、联机持久化和多进程协调。
